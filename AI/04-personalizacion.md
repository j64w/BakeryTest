# Personalización y Expansión Física

El jugador debe poder expandir físicamente su panadería a medida que
progresa, no solo mejorar estadísticas invisibles.

## Etapa inicial
- Habitación pequeña.
- Un horno.
- Una mesa.
- Pocos estantes.

## Etapas de progresión
- Cocina más grande (más espacio para estaciones).
- Más hornos (producción en paralelo).
- Área de clientes (espacio de espera/mesas para sentarse).
- Cafetería (nueva sección, posible nueva línea de productos: bebidas).
- Gran pastelería (versión final, máxima expansión visual).

## Notas de implementación
- Cada expansión debería ser un "Model" prediseñado en Roblox Studio que se
  activa/revela (o se construye mediante streaming de partes) al alcanzar
  el nivel o comprar la expansión.
- Es recomendable pensar la panadería como una escena modular con zonas
  claramente delimitadas (Zona de preparación / Zona de horneado / Zona de
  exhibición / Zona de clientes) para poder escalar el diseño sin rehacer
  todo el mapa.
